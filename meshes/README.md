# Meshes

The meshes are not stored in the repository. Place them in this directory; the examples read them from here.

## ONERA-OAT15A validation case
The structured Rizzi grids for the ONERA-OAT15A case (`examples/ONERA-OAT15A/`) are available at
<https://dpw.larc.nasa.gov/DPW8/ONERA_OAT15A/ONERA-Rizzi_Grids.REV00/>, which can be reached from the DPW8 grid page,
<https://www.aiaa-dpw.org/grids.html>. The case expects them at
`meshes/ONERA-ONERA-OAT15A-Rizzi/gridN/OAT15A_Rizzi_N.cgns`, for N = 1 to 7.
